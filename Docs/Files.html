Files Module

Appeal docsModule standardBasicAdvancedGlobals

Script functions provided by the Files module. Prefix each call with Files; arguments below are consumed in the listed order. Plugin support and behavior may vary.

Basic covers ordinary application and game operations. Advanced covers explicit setup, backend management, and tuning. This classification describes the current API; it does not certify that every backend yet provides the complete Basic-only game workflow required by the standard.


Basic functions

FunctionArgumentsDescription
ScanName: string, Path: stringRequests the module to scan.
OpenName: string, File: string, Mode: stringRequests the module to open.
CloseName: stringRequests the module to close.
ReadName: stringRequests the module to read.
WriteName: string, Value: stringRequests the module to write.
Read_AllFile: stringRequests the module to read all.
Write_AllFile: string, Value: stringRequests the module to write all.
JoinLeft: string, Right: stringRequests the module to join.
ParentPath: stringRequests the module to parent.
RelativeBase: string, Path: stringRequests the module to relative.
Add_ExtensionName: string, Extension: stringRequests the module to add extension.
Is_DirectoryPath: stringRequests the module to is directory.
Create_DirectoryPath: stringRequests the module to create directory.
Create_Game_ProjectName: stringRequests the module to create game project.
Append_LineFile: string, Value: stringRequests the module to append line.

Advanced functions

FunctionArgumentsDescription
InitName: stringInitializes the module and loads its default plugin.
DebugValue: stringEnables or disables diagnostic logging for the module and active plugin.
Set_PathsResources: stringSets the root Appeal resources path used by the module.

Globals
